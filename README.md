# 🚆 Railway Manager

A JavaScript console application for managing train trips and tickets.

## 📌 Features

- Display available trips
- Buy a ticket
- Display tickets
- Cancel a ticket
- Search for a ticket
- Filter trips by departure city
- Sort trips by price
- View statistics

## 🛠️ Technologies

- JavaScript
- Node.js
- prompt-sync

## ▶️ Run the project

Install the dependencies:

```bash
npm install
node yourfile.js
